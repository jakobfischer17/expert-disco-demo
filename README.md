# Multi-Language Greeting App

A simple React SPA (Single Page Application) that greets users in different languages.

## Features

- **10 Languages Supported**: English, Spanish, French, German, Italian, Japanese, Chinese, Arabic, Russian, and Portuguese
- **Personalized Greetings**: Enter your name to receive a personalized greeting
- **Clean, Modern UI**: Beautiful gradient design with responsive layout
- **Real-time Updates**: Greeting updates instantly as you change language or name

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```

### Development

Run the development server:
```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Build

Create a production build:
```bash
npm run build
```

### Lint

Run ESLint to check code quality:
```bash
npm run lint
```

## Technologies Used

- **React 19** - UI library
- **Vite** - Build tool and dev server
- **CSS3** - Styling with gradients and animations

## How to Use

1. Enter your name in the text input field (optional)
2. Select a language from the dropdown menu
3. See your personalized greeting displayed in the selected language!
