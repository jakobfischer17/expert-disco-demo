# expert-disco-demo

A simple web application that displays fascinating facts about language learning in an interactive banner.

## Features

- 💡 **Interactive Banner**: Displays interesting facts about language learning
- 🔄 **Rotating Facts**: 15 different facts that rotate automatically every 10 seconds
- 🖱️ **Manual Navigation**: Click the "Next Fact →" button to see the next fact anytime
- 🎨 **Beautiful Design**: Gradient backgrounds and smooth animations

## How to View

1. Open `index.html` in your web browser, or
2. Serve the files using a local web server:
   ```bash
   python3 -m http.server 8080
   ```
   Then navigate to `http://localhost:8080/` in your browser.

## Files

- `index.html` - Main HTML structure
- `styles.css` - Styling and animations
- `script.js` - JavaScript for fact rotation and interactivity
